# Prototype 2a Testing Plan

## Aim

The aim of this test is to evaluate whether users can understand
and complete the core sticky-note sorting interaction in the XR
prototype using a Meta Quest controller.

## Research Questions

1. Can users understand how to pick up and place sticky notes?
2. Can users complete the sorting task without assistance?
3. Are the controller interaction and instructions clear?
4. Do users experience any discomfort while using the VR prototype?

## Prototype

Participants will use a Meta Quest headset and controller to interact
with a virtual idea-space environment containing sticky notes and
four category boards.

## Task

Participants will:

1. Look around the virtual environment.
2. Select a sticky note from the Unsorted Ideas board.
3. Pick it up using the controller trigger.
4. Move the note to a category board.
5. Repeat the process for several sticky notes.

## Success Criteria

The following data will be recorded:

- Task completion
- Number of interaction errors
- Number of help requests
- Approximate completion time
- Participant ratings
- Observed usability problems

## Method

The researcher will observe the participant while the headset display
is streamed to a computer.

Participants will not be required to think aloud while completing
the task. Short questions will be asked after the task.

## Safety

Participants will remain in a small testing area and will not be
required to walk around.

Participants may stop the test at any time if they experience
discomfort.

## Post-task Questions

Participants will complete a short questionnaire and interview after
the task.
